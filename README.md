# Dreamy Creations

A simple art showcase website created to display handmade artwork and
help customers explore the available creations and place orders through Instagram.

## About the Project

Dreamy Creations is a website I developed for an artist to showcase her
handmade artwork online.

The website provides:

- A visual gallery of artwork
- Different artwork collections
- A link to the artist's Instagram
- An easy way for visitors to contact/order through Instagram

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Purpose

The goal of the website is to give the artist a simple online presence
where people can view her artwork and visit her Instagram to enquire
about or order pieces.
